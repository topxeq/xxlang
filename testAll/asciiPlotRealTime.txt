=== ASCII Plot Real-Time Demo - Expected Output ===

Initial screen:
=== ASCII Plot Real-Time Demo ===
Press a-z to change plot, q to exit

[ASCII plot displayed with animation]
Press a-z (q=quit). Last: '' val=0
Frame: 1 | a[0][2]: 1 | a[0][4]: 4

When user presses 'a':
- Display updates to show: Last: 'a' val=0
- Plot shape changes (a[0][4] value affects the curve)

When user presses 'm':
- Display updates to show: Last: 'm' val=12
- Plot shape changes accordingly

When user presses 'z':
- Display updates to show: Last: 'z' val=25
- Maximum value change

When user presses 'q':
- Script exits with message: "Exiting..."

=== Technical Notes ===

1. Non-blocking input: Uses getChar() for real-time key detection
2. Concurrent execution: Input handler and display run in separate goroutines
3. Communication: Global variables used for thread-safe key event passing
4. Frame rate: 100ms per frame (10 FPS)
5. Input polling: 10ms interval for responsive key detection

=== Running the Script ===

For proper keyboard input, run in an interactive console window:
  cd repo
  ./xxl.exe testAll/asciiPlotRealTime.xxl

DO NOT use pipe or redirect (these won't capture key presses):
  WRONG: echo "q" | ./xxl.exe testAll/asciiPlotRealTime.xxl
  WRONG: ./xxl.exe testAll/asciiPlotRealTime.xxl < nul
