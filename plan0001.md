# Xxlang HTTP Server Mode Implementation Plan

## Overview

Implement a multi-purpose HTTP/HTTPS server mode in Xxlang that allows scripts to handle web requests, microservices, and dynamic web pages. The server supports simultaneous HTTP and HTTPS ports.

## Command Line Interface

```bash
# Start server with default ports (HTTP:80, HTTPS:443)
xxl serve -web=./web -ms=./ms -cert=./cert

# Start with custom ports
xxl serve -web=./web -ms=./ms -cert=./cert -http=8080 -https=8443

# Start HTTP only (no HTTPS)
xxl serve -web=./web -ms=./ms -http=8080

# Start with config file
xxl serve -config=server.json
```

### Command Line Parameters

| Parameter | Description | Default |
|-----------|-------------|---------|
| `-web` | Web root path for static files and dynamic pages | `.` |
| `-ms` | Microservice root path for API scripts | `.` |
| `-cert` | Certificate path (contains server.crt and server.key) | `.` |
| `-http` | HTTP port (0 to disable) | `80` |
| `-https` | HTTPS port (0 to disable) | `443` |
| `-config` | Configuration file path | - |

### Certificate Files

Fixed file names in the certificate path:
- `server.crt` - SSL certificate file
- `server.key` - SSL private key file

## Architecture

### 1. New Object Types

Create `pkg/objects/http.go`:

```go
// HttpReq wraps http.Request for script access
type HttpReq struct {
    Value   *http.Request
    Members map[string]Object
}

// HttpResp wraps http.ResponseWriter for script access
type HttpResp struct {
    Value   http.ResponseWriter
    Members map[string]Object
}

// HttpMux wraps http.ServeMux for route registration
type HttpMux struct {
    Value *http.ServeMux
}
```

### 2. Global Variables (Available in Server Mode)

Scripts can directly reference these global variables:

| Variable | Type | Description |
|----------|------|-------------|
| `requestG` | HttpReq | Current HTTP request object |
| `responseG` | HttpResp | Current HTTP response object |
| `paraMapG` | Map | Parsed form/URL parameters |
| `reqNameG` | String | Request path name (without prefix) |
| `reqUriG` | String | Full request URI |
| `methodG` | String | HTTP method (GET/POST/PUT/DELETE/etc) |
| `webPathG` | String | Web root directory |
| `basePathG` | String | Microservice root directory |
| `msPathG` | String | Microservice root directory (alias for basePathG) |
| `runModeG` | String | Always "server" in server mode |

### 3. Built-in Functions

Create `pkg/objects/builtin_http.go`:

| Function | Signature | Description |
|----------|-----------|-------------|
| `writeResp` | `writeResp(response, content)` | Write content to HTTP response |
| `setRespHeader` | `setRespHeader(response, key, value)` | Set response header |
| `getReqHeader` | `getReqHeader(request, key)` | Get request header value |
| `getReqHeaders` | `getReqHeaders(request)` | Get all headers as map |
| `setCookie` | `setCookie(response, name, value, options?)` | Set cookie |
| `getCookie` | `getCookie(request, name)` | Get cookie value |
| `parseForm` | `parseForm(request)` | Parse form data, returns map |
| `parseJSON` | `parseJSON(request)` | Parse JSON body, returns object |
| `serveFile` | `serveFile(response, request, path)` | Serve static file |
| `redirect` | `redirect(response, url, code?)` | HTTP redirect (default 302) |
| `status` | `status(response, code)` | Set HTTP status code |
| `getMimeType` | `getMimeType(path)` | Get MIME type by file extension |

### 4. Server Implementation

Create `pkg/server/server.go`:

```go
package server

import (
    "fmt"
    "net/http"
    "os"
    "path/filepath"
    "strings"

    "github.com/topxeq/xxlang/pkg/compiler"
    "github.com/topxeq/xxlang/pkg/objects"
    "github.com/topxeq/xxlang/pkg/vm"
)

// Config holds server configuration
type Config struct {
    HTTPPort  int    `json:"httpPort"`
    HTTPSPort int    `json:"httpsPort"`
    WebPath   string `json:"webPath"`
    MSPath    string `json:"msPath"`
    CertPath  string `json:"certPath"`
}

// Server represents the HTTP/HTTPS server
type Server struct {
    Config  Config
    Mux     *http.ServeMux
    Verbose bool
}

// NewServer creates a new server instance
func NewServer(cfg Config) *Server {
    return &Server{
        Config: cfg,
        Mux:    http.NewServeMux(),
    }
}

// Start starts the HTTP and HTTPS servers
func (s *Server) Start() error {
    // Setup routes
    s.setupRoutes()

    errChan := make(chan error, 2)

    // Start HTTP server
    if s.Config.HTTPPort > 0 {
        go func() {
            addr := fmt.Sprintf(":%d", s.Config.HTTPPort)
            fmt.Printf("[HTTP] Starting server on port %d\n", s.Config.HTTPPort)
            errChan <- http.ListenAndServe(addr, s.Mux)
        }()
    }

    // Start HTTPS server
    if s.Config.HTTPSPort > 0 {
        go func() {
            certFile := filepath.Join(s.Config.CertPath, "server.crt")
            keyFile := filepath.Join(s.Config.CertPath, "server.key")

            if _, err := os.Stat(certFile); os.IsNotExist(err) {
                fmt.Printf("[HTTPS] Certificate file not found: %s\n", certFile)
                errChan <- fmt.Errorf("certificate not found: %s", certFile)
                return
            }

            addr := fmt.Sprintf(":%d", s.Config.HTTPSPort)
            fmt.Printf("[HTTPS] Starting server on port %d\n", s.Config.HTTPSPort)
            errChan <- http.ListenAndServeTLS(addr, certFile, keyFile, s.Mux)
        }()
    }

    return <-errChan
}

// setupRoutes configures URL routing
func (s *Server) setupRoutes() {
    // Microservice routes (prefix: /ms/ or /api/)
    s.Mux.HandleFunc("/ms/", s.handleMicroservice)
    s.Mux.HandleFunc("/api/", s.handleMicroservice)

    // Web routes (everything else)
    s.Mux.HandleFunc("/", s.handleWebRequest)
}

// handleMicroservice handles microservice requests
func (s *Server) handleMicroservice(res http.ResponseWriter, req *http.Request) {
    res.Header().Set("Access-Control-Allow-Origin", "*")
    res.Header().Set("Access-Control-Allow-Headers", "*")
    res.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")

    if req.Method == "OPTIONS" {
        res.WriteHeader(200)
        return
    }

    req.ParseForm()

    // Extract service name from path
    path := req.URL.Path
    if strings.HasPrefix(path, "/ms/") {
        path = path[4:]
    } else if strings.HasPrefix(path, "/api/") {
        path = path[5:]
    }

    // Find script file
    scriptPath := filepath.Join(s.Config.MSPath, path)
    if !strings.HasSuffix(scriptPath, ".xxl") {
        scriptPath += ".xxl"
    }

    // Check if file exists
    if _, err := os.Stat(scriptPath); os.IsNotExist(err) {
        res.WriteHeader(404)
        res.Write([]byte("Service not found: " + path))
        return
    }

    // Execute script
    s.executeScript(scriptPath, res, req)
}

// handleWebRequest handles web page requests
func (s *Server) handleWebRequest(res http.ResponseWriter, req *http.Request) {
    path := req.URL.Path

    // Default to index.xxl for root
    if path == "/" {
        path = "/index.xxl"
    }

    // Check for dynamic page (.xxl)
    scriptPath := filepath.Join(s.Config.WebPath, path)

    if strings.HasSuffix(scriptPath, ".xxl") {
        if _, err := os.Stat(scriptPath); err == nil {
            s.executeScript(scriptPath, res, req)
            return
        }
    }

    // Serve static file
    staticPath := filepath.Join(s.Config.WebPath, path)
    http.ServeFile(res, req, staticPath)
}

// executeScript executes an Xxlang script for HTTP request
func (s *Server) executeScript(scriptPath string, res http.ResponseWriter, req *http.Request) {
    // Read script
    code, err := os.ReadFile(scriptPath)
    if err != nil {
        res.WriteHeader(500)
        res.Write([]byte("Failed to read script: " + err.Error()))
        return
    }

    // Parse form data
    req.ParseForm()
    paraMap := make(map[string]string)
    for k, v := range req.Form {
        if len(v) > 0 {
            paraMap[k] = v[0]
        }
    }

    // Parse URL query parameters
    for k, v := range req.URL.Query() {
        if len(v) > 0 && paraMap[k] == "" {
            paraMap[k] = v[0]
        }
    }

    // Extract request name
    reqName := req.URL.Path
    if idx := strings.LastIndex(reqName, "/"); idx >= 0 {
        reqName = reqName[idx+1:]
    }

    // Run script with globals
    result, err := RunScriptOnHttp(string(code), scriptPath, res, req, paraMap, map[string]interface{}{
        "basePathG": s.Config.WebPath,
        "msPathG":   s.Config.MSPath,
        "runModeG":  "server",
    })

    if err != nil {
        res.WriteHeader(500)
        res.Write([]byte("Script error: " + err.Error()))
        return
    }

    // Special return value means response already handled
    if result == "TX_END_RESPONSE_XT" {
        return
    }

    // Write result as response
    if result != "" {
        res.Header().Set("Content-Type", "text/html; charset=utf-8")
        res.Write([]byte(result))
    }
}

// RunScriptOnHttp executes Xxlang code for HTTP request
func RunScriptOnHttp(code, scriptPath string, res http.ResponseWriter, req *http.Request,
    paraMap map[string]string, globals map[string]interface{}) (string, error) {

    // Compile
    bytecode, err := compiler.Compile([]byte(code), nil)
    if err != nil {
        return "", err
    }

    // Prepare globals
    env := make(map[string]interface{})
    for k, v := range globals {
        env[k] = v
    }
    env["requestG"] = req
    env["responseG"] = res
    env["paraMapG"] = paraMap
    env["reqNameG"] = req.URL.Path
    env["reqUriG"] = req.RequestURI
    env["methodG"] = req.Method

    // Create VM with globals
    vm := vm.NewRegVMWithGlobalsMap(bytecode, env)

    // Run
    result, err := vm.Run()
    if err != nil {
        return "", err
    }

    if result == nil || result == objects.NULL {
        return "", nil
    }

    return result.Inspect(), nil
}
```

### 5. CLI Integration

Modify `cmd/xxl/main.go`:

```go
case "serve":
    if err := serveCmd(interpreterArgs[1:]); err != nil {
        fmt.Fprintf(os.Stderr, "Error: %v\n", err)
        os.Exit(1)
    }

func serveCmd(args []string) error {
    // Parse arguments
    cfg := server.Config{
        HTTPPort:  80,
        HTTPSPort: 443,
    }

    for i := 0; i < len(args); i++ {
        switch {
        case strings.HasPrefix(args[i], "-web="):
            cfg.WebPath = strings.TrimPrefix(args[i], "-web=")
        case strings.HasPrefix(args[i], "-ms="):
            cfg.MSPath = strings.TrimPrefix(args[i], "-ms=")
        case strings.HasPrefix(args[i], "-cert="):
            cfg.CertPath = strings.TrimPrefix(args[i], "-cert=")
        case strings.HasPrefix(args[i], "-http="):
            fmt.Sscanf(strings.TrimPrefix(args[i], "-http="), "%d", &cfg.HTTPPort)
        case strings.HasPrefix(args[i], "-https="):
            fmt.Sscanf(strings.TrimPrefix(args[i], "-https="), "%d", &cfg.HTTPSPort)
        case strings.HasPrefix(args[i], "-config="):
            // Load from config file
            configFile := strings.TrimPrefix(args[i], "-config=")
            data, err := os.ReadFile(configFile)
            if err != nil {
                return fmt.Errorf("failed to read config: %v", err)
            }
            if err := json.Unmarshal(data, &cfg); err != nil {
                return fmt.Errorf("failed to parse config: %v", err)
            }
        }
    }

    // Set defaults
    if cfg.WebPath == "" {
        cfg.WebPath = "."
    }
    if cfg.MSPath == "" {
        cfg.MSPath = "./ms"
    }
    if cfg.CertPath == "" {
        cfg.CertPath = "."
    }

    // Create and start server
    srv := server.NewServer(cfg)
    fmt.Printf("Xxlang Server v%s\n", Version)
    fmt.Printf("Web path: %s\n", cfg.WebPath)
    fmt.Printf("Microservice path: %s\n", cfg.MSPath)
    fmt.Printf("Certificate path: %s\n", cfg.CertPath)

    return srv.Start()
}
```

## Example Scripts

### Microservice: add.xxl

```xxl
// ms/add.xxl - Addition microservice
// Access: /ms/add?a1=10&a2=20

// Parameters are directly available
var a1 = toInt(paraMapG["a1"])
var a2 = toInt(paraMapG["a2"])
var result = a1 + a2

// Set response type
setRespHeader(responseG, "Content-Type", "application/json")

// Write JSON response
writeResp(responseG, toJson({
    "success": true,
    "result": result,
    "a1": a1,
    "a2": a2
}))

// Signal response complete
return "TX_END_RESPONSE_XT"
```

### Router: router.xxl

```xxl
// ms/router.xxl - Main API router
// Access: /ms/router?action=add&a1=10&a2=20

var action = paraMapG["action"]

switch (action) {
    case "add":
        var result = toInt(paraMapG["a1"]) + toInt(paraMapG["a2"])
        setRespHeader(responseG, "Content-Type", "application/json")
        writeResp(responseG, toJson({"result": result}))

    case "multiply":
        var result = toInt(paraMapG["a1"]) * toInt(paraMapG["a2"])
        setRespHeader(responseG, "Content-Type", "application/json")
        writeResp(responseG, toJson({"result": result}))

    default:
        status(responseG, 400)
        writeResp(responseG, toJson({"error": "unknown action"}))
}

return "TX_END_RESPONSE_XT"
```

### User API with JSON Body: user.xxl

```xxl
// ms/user.xxl - User management API

var method = methodG

if (method == "GET") {
    // Return user list
    var users = [
        {"id": 1, "name": "Alice", "email": "alice@example.com"},
        {"id": 2, "name": "Bob", "email": "bob@example.com"}
    ]
    setRespHeader(responseG, "Content-Type", "application/json")
    writeResp(responseG, toJson(users))

} else if (method == "POST") {
    // Create user from JSON body
    var body = parseJSON(requestG)

    // Validate
    if (body["name"] == "" || body["email"] == "") {
        status(responseG, 400)
        writeResp(responseG, toJson({"error": "name and email required"}))
    } else {
        // Return created user
        setRespHeader(responseG, "Content-Type", "application/json")
        status(responseG, 201)
        writeResp(responseG, toJson({
            "id": 3,
            "name": body["name"],
            "email": body["email"]
        }))
    }
}

return "TX_END_RESPONSE_XT"
```

| `/page.xxl` | Web handler | `web/page.xxl` |
| `/css/style.css` | Static file | `web/css/style.css` |
| `/ms/add` | MS handler | `ms/add.xxl` |

## Notes

1. **Global Variables**: Xxlang scripts reference global variables directly without `global` keyword
2. **Response End**: Return `"TX_END_RESPONSE_XT"` to indicate response is complete
3. **CORS**: Enabled by default for microservice routes
4. **Static Files**: Automatically served from web root if no matching `.xxl` script
5. **Certificate Files**: Fixed names `server.crt` and `server.key` in certificate path
